# مغامرة الأسئلة المجنونة

## بنية الملفات
```
index.html    اللعبة          builder.html  المحرّر (أسئلة + إعدادات)
style.css     التصميم          builder.js    منطق المحرّر
config.js     البيانات الافتراضية   store.js      دمج ما حفظه المحرّر
game.js       منطق اللعبة
```
جميع الروابط نسبية، فتعمل داخل مسار المستودع على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل الملفات في جذره.
2. من Settings ← Pages اختر Branch: `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## التخصيص
افتح `config.js`: كل مجموعة إعدادات لها تعليق يوضح مكانها (النصوص، اللاعبون، المظهر، القواعد، الرسائل، الألوان، الأسئلة).

## المحرّر
افتح `builder.html` (أو زر 🛠️ في اللعبة): أضف الأسئلة وعدّل الإعدادات. «حفظ» يخزّنها في متصفحك فقط. للنشر للجميع: «تنزيل config.js» ثم استبدل به الملف في المستودع.
